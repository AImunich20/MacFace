## MacFace 1.3

First MacFace release, based on glance 1.2.

- Renamed the app to MacFace (new bundle ID `com.aimunich20.macface`)
- Updates now come from [MacFace-releases](https://github.com/AImunich20/MacFace-releases)
- Recognition, liveness checks and unlocking work the same as glance 1.2

If you used glance before, set MacFace up from scratch: enroll your face and grant Camera and Accessibility again.
